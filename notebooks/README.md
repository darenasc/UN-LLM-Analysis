# Analysis

Exploratory analyses, LLM experiments, and visualizations.

The project uses LLMs to analyze UN noon briefings, focusing on:

- [**SDG Mentions:**](SDG_mentions_in_briefings.ipynb) Identifying references to the UN Sustainable Development Goals (SDGs).
- [**Sentiment Analysis:**](sentiment_tone_visualization.ipynb) Classifying the sentiment and tone of briefing sections.
- [**Country Heatmap:**](Country_mentions.ipynb) Visualizing country mentions using maps and heatmaps.
- [**Issue Proportion:**](./issue_analysis/02_issue_proportion_in_briefings.ipynb) Tracking major global issues and their trends over time.
